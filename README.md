# Olá Mundo .NET com xUnit

Projeto desenvolvido para praticar testes automatizados utilizando **.NET** e **xUnit**.

## 📋 Sobre o projeto

Este projeto tem como objetivo demonstrar a criação e execução de testes automatizados em uma aplicação .NET utilizando o framework xUnit.

## 🛠️ Tecnologias utilizadas

- C#
- .NET
- xUnit
- Visual Studio Code
- Git e GitHub

## 🧪 Testes

Os testes foram desenvolvidos utilizando o **xUnit**, permitindo verificar automaticamente o comportamento esperado da aplicação.

Para executar os testes, utilize:

```bash
dotnet test
